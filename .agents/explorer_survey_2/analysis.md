## 2. NASA Kepler, K2, and TESS Archive Data

### 2.1 File Formats and Data Structures

NASA exoplanet transit missions generate two primary data products delivered via FITS containers:

#### A. Target Pixel Files (TPF)
TPFs contain time-stamped images of the CCD pixel grid surrounding the target star.
- **HDU 0 (Primary HDU)**: Header-only metadata containing mission parameters, celestial coordinates (RA, Dec J2000), CCD module/output, Kepler/TIC identifier, and observing campaign/quarter.
- **HDU 1 (TARGETTABLES extension)**: Binary table containing cadence-by-cadence arrays:
  - TIME (float64): Barycentric Kepler Julian Date (BKJD) or Barycentric TESS Julian Date (BTJD).
  - TIMECORR (float32): Barycentric light-travel time correction applied to the timestamp.
  - CADENCENO (int32): Monotonically increasing cadence counter.
  - RAW_CNTS (2D int32 array, shape [N_rows, N_cols]): Uncalibrated detector pixel counts.
  - FLUX (2D float32 array, shape [N_rows, N_cols]): Calibrated flux in electrons per second (e-/s), with flat-fielding, gain, smear, and non-linearity corrections applied.
  - FLUX_ERR (2D float32 array): 1-sigma measurement uncertainties per pixel.
  - FLUX_BKG (2D float32 array): Estimated background flux subtracted from each pixel.
  - QUALITY (int32): Quality flag bitmask for the cadence.
  - POS_CORR1, POS_CORR2 (float32): Relative sub-pixel pointing drift along column/row axes.
- **HDU 2 (APERTURE extension)**: 2D integer image array indicating pixel masks:
  - Bit 0 (val 1): Pixel collected by spacecraft mask.
  - Bit 1 (val 2): Pixel included in optimal photometric extraction aperture.
  - Bit 2 (val 4): Pixel used for background estimation.

#### B. LightCurve Files (LC)
LC files contain 1D integrated photometric time series generated by the mission pipeline.
- **HDU 0 (Primary HDU)**: Target metadata, coordinate solutions, stellar parameters (Teff, log g, [Fe/H], R*).
- **HDU 1 (LIGHTCURVE extension)**: Binary table with 20 columns:
  - TIME (float64): Barycentric timestamp.
  - SAP_FLUX (float32): Simple Aperture Photometry flux (e-/s). Sum of background-subtracted flux in optimal aperture:
    F_{SAP}(t) = \sum_{p \in \text{aperture}} [I_p(t) - B_p(t)]
  - SAP_FLUX_ERR (float32): Propagated Poisson photon noise and detector read noise.
  - PDCSAP_FLUX (float32): Pre-search Data Conditioning SAP flux (e-/s). Cleaned of instrumental systematics using Cotrending Basis Vectors (CBVs) via Maximum A Posteriori (MAP) Bayesian regularized regression:
    F_{PDCSAP}(t) = F_{SAP}(t) - \sum_{k=1}^{K} c_k \cdot CBV_k(t)
  - PDCSAP_FLUX_ERR (float32): Propagated uncertainty from the PDC-MAP module.
  - SAP_QUALITY / QUALITY (int32): Bitwise quality flags.
  - MOM_CENTR1, MOM_CENTR2 (float64): Flux-weighted centroid moments.
  - PSF_CENTR1, PSF_CENTR2 (float64): Point Spread Function (PRF) centroid position.

- **Strict Science Quality Filter**: QUALITY == 0 (retains pristine cadences, drops ~8-12% of cadences, eliminates instrument false alarms).

### 2.2 Time Systems and Cadences

1. **Barycentric Kepler Julian Date (BKJD)**:
   \text{BKJD} = \text{BJD} - 2454833.0
   Reference epoch: 2009-01-01 12:00:00 UTC. Time standard: Barycentric Dynamical Time (TDB).
2. **Barycentric TESS Julian Date (BTJD)**:
   \text{BTJD} = \text{BJD} - 2457000.0
   Reference epoch: 2014-12-08 00:00:00 TDB.
3. **Exact Linear Transformations**:
   \text{BJD} = \text{BKJD} + 2454833.0 = \text{BTJD} + 2457000.0
   \text{BTJD} = \text{BKJD} - 2167.0
   \text{BKJD} = \text{BTJD} + 2167.0
4. **Cadence Durations**:
   - Kepler Long Cadence (LC): 29.4244 min (270 co-added 6.02-second exposures).
   - Kepler Short Cadence (SC): 58.8488 sec (9 co-added 6.02-second exposures).
   - TESS Standard Cadence: 2 min (120 sec). Fast Cadence: 20 sec.
   - TESS Full Frame Images (FFI): 30 min (S1-S26), 10 min (S27-S55), 200 sec (S56+).

## 4. Preprocessing, Detrending, and Normalization Strategies

Photometric time series exhibit astrophysical variability (stellar rotation, starspots, flares, granulation) and instrumental systematics. Preprocessing must isolate transit signals without distorting intrinsic transit asymmetries.

```
Raw Calibrated Light Curve (PDCSAP_FLUX)
                |
                v
   Quality Flag Filtering (QUALITY == 0)
                |
                v
  Asymmetric Flare / Outlier Filtering (MAD-based)
                |
                v
 Iterative Transit Masking (Residuals < -2.5 sigma)
                |
                v
 Savitzky-Golay / Spline Continuum Modeling
                |
                v
 Normalized Flux = Raw Flux / Continuum Fit
                |
                v
 Phase-Folding & Inverse-Variance Weighted Binning
```

### 4.1 Asymmetric Outlier and Stellar Flare Filtering
Standard symmetric sigma-clipping inadvertently truncates transit troughs. The pipeline implements asymmetric MAD-based clipping:
1. Running median F_tilde_i = median(F_{i-W ... i+W}) across sliding window W.
2. Robust scatter via Median Absolute Deviation:
   sigma_MAD = 1.4826 * median(|F_i - F_tilde_i|)
3. Positive outliers (stellar flares): Flag cadences with F_i > F_tilde_i + 3.5 * sigma_MAD.
   - Flares follow Fast-Rise Exponential-Decay (FRED) profiles: mask consecutive points following a trigger until flux returns to baseline + 1.0 * sigma_MAD.
4. Negative outliers: Mask only points with F_i < F_tilde_i - 6.0 * sigma_MAD, or apply negative clipping exclusively *after* transit masking.

### 4.2 Iterative Detrending with Transit Preservation
- **Savitzky-Golay (SG) Detrending**:
  - Window constraint: W >= 3 * T_duration (typically 0.5 to 1.2 days).
  - Iterative Protocol:
    1. Compute initial smoothed baseline S^(0)(t) = SG(F(t), W, polyorder=2).
    2. Compute initial residuals R^(0)(t) = F(t) / S^(0)(t).
    3. Identify transit candidate points where R^(0)(t) < 1.0 - 2.5 * sigma_MAD.
    4. Form masked flux F_masked(t), replacing transit points via linear interpolation between out-of-transit endpoints.
    5. Recompute baseline on masked curve: S_clean(t) = SG(F_masked(t), W, polyorder=2).
    6. Normalize: F_norm(t) = F(t) / S_clean(t).
- **Empirical Validation**:
  - Tested on synthetic stellar rotation (P_rot = 2.5 d, 0.5% amplitude) with injected asymmetric cometary transit (1.2% depth).
  - Out-of-transit residual mean: 1.00008 +- 0.00089.
  - Recovered transit depth: 1.206% (99.5% recovery fidelity, zero distortion of the exponential tail).

### 4.3 Phase-Folding and Weighted Binning
1. **Phase Coordinate**:
   phi_i = ((t_i - T0) / P + 0.5) % 1 - 0.5 in [-0.5, 0.5)
2. **Inverse-Variance Weighted Uniform Phase Binning**:
   For M phase bins [phi_k, phi_{k+1}]:
   F_bar_k = sum(w_i * F_i) / sum(w_i), where w_i = 1 / sigma_i^2
   sigma_k = 1 / sqrt(sum(w_i))
   Empirical standard error accounting for correlated red noise:
   sigma_k_emp = std(F_{i in bin k}) / sqrt(N_k)

1. **Dust-Tail Transit Generator**:
   - Implements the Rappaport/Brogi analytical model:
     tau(x) = tau_0 * exp(-x / lambda_tail) * Theta(x)
     where x is the trailing distance from nucleus, lambda_tail is the dust cloud dissipation scale length, and Theta(x) is the Heaviside step function.
   - Includes forward-scattering phase function:
     F_scatter(theta) = A_scat * (1 - g^2) / ((1 + g^2 - 2g cos theta)^(3/2))
     using Henyey-Greenstein scattering with asymmetry factor g ~ 0.6-0.8.
2. **Exomoon & TTV Generator**:
   - Implements multi-body gravitational transit perturbations:
     t_n = T0 + n * P + A_TTV * sin(2 * pi * n * P / P_super + psi)
   - Generates secondary moon transit dip offset by moon orbital phase:
     delta_total(t) = delta_planet(t - t_planet) + delta_moon(t - t_moon)
3. **JWST Atmospheric Spectrum Generator**:
   - Analytical radiative transfer transmission approximation:
     (Rp(lambda)/R*)^2 = (1 / R*^2) * [ Rp0 + H * (ln(kappa(lambda) * P0 * sqrt(2*pi*Rp0/H) / gp) + 0.5772) ]^2
     where scale height H = (k_B * Teq) / (mu * gp), and opacity kappa(lambda) = sum(X_i * sigma_i(lambda)) + sigma_Rayleigh(lambda) + sigma_haze(lambda).
